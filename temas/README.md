# temas/

Peles do Caderno. Cada tema é **vocabulário visual solto** — tokens, arte,
som —, sem nenhuma tela dentro. É isso que permite aplicá-lo à interface
atual em vez de manter dois apps para sempre.

| tema | onde está vivo | estado |
|---|---|---|
| **pixel** (`temas/pixel/`) | `retro/` — o Caderno 2.0 | pronto e guardado para enxertar no app principal |

O tema **clássico** não mora aqui: ele é o próprio `css/app.css`. Quando um
segundo tema for enxertado no app principal, vale extrair os tokens dele
para `temas/classico/tokens.css` e deixar os dois no mesmo pé.
